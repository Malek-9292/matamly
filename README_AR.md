# مشروع مطعمي — دليل الحفظ والتعديل

## ما تم تنفيذه

المشروع يحتوي على صفحة مطعم عربية متجاوبة، سلة طلب، إرسال الطلب إلى واتساب، خيارات تخصيص للساندويتشات والمقبلات والصواني والجاطات، جدولة توفر الأصناف، مناطق توصيل ورسوم قابلة للتعديل، حد أدنى للطلب، وطرق دفع تظهر داخل الطلب: الدفع عند الاستلام وK-Net وبطاقة ائتمان.

تمت إضافة لوحة إدارة مخفية على `/admin`، وواجهة كاشير محمية على `/cashier` تعرض الطلبات الجديدة تلقائياً على جهاز Samsung. الطلبات تُحفظ مؤقتاً على خادم التطبيق، ويجب لاحقاً نقل التخزين إلى قاعدة بيانات إنتاجية قبل الإطلاق التجاري النهائي.

## التشغيل على جهاز آخر

1. ثبّت Node.js وpnpm.
2. فك ضغط الأرشيف.
3. افتح الطرفية داخل مجلد المشروع.
4. نفّذ `pnpm install`.
5. أنشئ ملف `.env` وضع فيه كلمة مرور الإدارة في `ADMIN_PASSWORD`.
6. للتطوير شغّل `pnpm dev`.
7. للإنتاج شغّل `pnpm build` ثم `pnpm start`.

## المسارات

- `/` صفحة العميل.
- `/admin` لوحة الإدارة المخفية.
- `/cashier` واجهة الكاشير على جهاز Samsung.

## إعداد المناطق والرسوم

من لوحة الإدارة افتح الإعدادات، وعدّل المناطق بهذا الشكل، منطقة واحدة في كل سطر:

```text
حولي:1
السالمية:1
الفروانية:1.25
```

القيمة بعد النقطتين هي رسوم التوصيل بالدينار الكويتي. ويمكن تعديل الحد الأدنى للطلب من نفس الشاشة.

## الطباعة

واجهة الكاشير جاهزة وتحتوي على زر طباعة وتنسيق مناسب للفواتير. عند توصيل Epson TM-T20III بالراوتر عبر Ethernet ومعرفة عنوان IP، يتم استكمال طبقة الطباعة الشبكية باستخدام ESC/POS أو تطبيق Android وسيط. لا يتم حفظ بيانات البطاقات داخل المشروع.

## ملاحظات مهمة قبل الإطلاق

- يجب نقل الطلبات من التخزين المؤقت في الذاكرة إلى قاعدة بيانات دائمة.
- يجب ربط K-Net وبطاقات الائتمان ببوابة دفع معتمدة قبل قبول الدفع الإلكتروني الفعلي.
- يجب تغيير كلمة مرور الإدارة الافتراضية وعدم مشاركتها.
- لا تضع مفاتيح الدفع أو كلمات المرور داخل ملفات الواجهة الأمامية.

## التعديل

أهم الملفات:

- `client/src/pages/Home.tsx` صفحة العميل.
- `client/src/pages/Admin.tsx` لوحة الإدارة.

- `client/src/index.css` التصميم والتنسيق.
- `server/_core/index.ts` API الطلبات وتسجيل دخول الإدارة.
- `client/src/App.tsx` مسارات الموقع.
